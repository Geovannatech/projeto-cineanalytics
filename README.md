# 🎬 CineAnalytics - Pipeline & Análise de Dados de Filmes

Projeto de análise de dados de filmes desenvolvido do zero para demonstrar o ciclo completo de ETL (Extração, Transformação e Carga), modelagem de dados e visualização de métricas.

---

## 🛠️ Tecnologias Utilizadas

* **Python:** Ingestão de dados via API e manipulação de DataFrames com `pandas` e `requests`.
* **SQL / SQLite:** Armazenamento relacional e estruturação do banco de dados.
* **Power BI:** Criação de dashboard interativo com métricas de negócio (Lucro e ROI).
* **Git & GitHub:** Controle de versão e documentação.
